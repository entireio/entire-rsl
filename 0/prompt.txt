Goal. Fetch only when every key in the repository's own config is known to be safe. An unknown key refuses the fetch, so the next git setting that runs a program fails closed instead of running.

Scope. It covers the same gate as today: syncGittufRefs before SyncGittufRefs, used by refresh, --fetch and the offered fetch. Read-only commands are unchanged. Global and system config stay trusted.running.
